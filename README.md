# ShashKi — Шашки с нейроэволюцией и минимаксом

Учебный проект на **C# (Windows Forms)**: игра в шашки, где компьютер обучается **генетическим алгоритмом** (нейроэволюция) и играет в гибридном режиме — нейросеть + **минимакс с альфа-бета-отсечением**.

## Возможности

- **Полные правила русских шашек:** обязательное взятие, цепочки взятий, дамки (в т.ч. бой дамки по диагонали на любое расстояние), превращение в дамку, ничья по правилу 40 ходов без взятия
- **Генетический алгоритм обучения:**
  - популяция нейросетей, каждая оценивается в серии игр против случайных соперников
  - фитнес по ТЗ: победа `+1`, ничья `0`, поражение `−2`
  - элитизм (15 лучших переходят в следующее поколение) + 15 новых случайных особей
  - **унивицированный кроссовер** весов и смещений
  - **гауссова мутация** весов, смещений и параметра `KingValue`
  - турнирный отбор
- **Гибридный ИИ:** с заданной вероятностью (`neuralChance = 0.1`) ход делает нейросеть, иначе — **минимакс** с настраиваемой глубиной (`difficulty = 3`)
- **Нейросеть:** архитектура `32 → 64 → 32 → 1`, сигмоидная активация, вход — 32 признака доски в формате `{−K, −1, 0, 1, K}`
- **Эволюция параметра `KingValue`** — сеть сама подбирает ценность дамки относительно шашки
- **Визуализация:** доска из панелей, анимация ходов компьютера с задержками, подсветка выбранной шашки/возможных ходов/взятий
- **Обучение в фоне** (`BackgroundWorker`) с прогресс-баром

## Технические детали

- **Генетическая тренировка** — `GeneticCheckers` (популяция, кроссовер, мутация, симуляция игр)
- **Минимакс** — `MinimaxCheckers` с альфа-бета-отсечением и оценочной функцией (шашка = 3, дамка = 5)
- **Ходы** — `Move` (с цепочками `JumpedPieces`), `Checker` (цвет + флаг дамки)
- **Формат входа сети** — только тёмные клетки, свои фигуры положительны, чужие отрицательны

## Сборка

Требуется **Visual Studio** (Windows Forms, .NET Framework / .NET).

## Управление

1. **Обучить нейросеть** — запуск эволюции (100 поколений по умолчанию)
2. Выбрать цвет (`radioButton`) и кто ходит первым (`comboBox`)
3. **Начать игру** — клик по своей шашке, затем по подсвеченной клетке
4. Компьютер отвечает автоматически (нейросеть / минимакс)

## Структура

| Класс | Назначение |
|---|---|
| `Individual` | Особь (веса, смещения, `KingValue`, фитнес) |
| `GeneticCheckers` | ГА, нейросеть, правила игры, симуляция |
| `MinimaxCheckers` | Минимакс с α-β-отсечением |
| `Form1` | UI, игровая логика, гибридный выбор хода |
| `Move` / `Checker` | Модель хода и фигуры |
